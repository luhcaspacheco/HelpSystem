Requisitos: nodejs

Este projeto é feito em React.
Ao baixar o projeto, digite `npm i` no terminal, no root da pasta.
Espere os arquivos serem baixados, e quando estiver tudo baixado, digite `npm run build` para compilar, somente na primeira vez.
Para rodar o projeto no navegador, digite `npm run dev` e acesse o link que ele retorne.

Para quaisquer dúvidas, falar com Sakiri Moon.
